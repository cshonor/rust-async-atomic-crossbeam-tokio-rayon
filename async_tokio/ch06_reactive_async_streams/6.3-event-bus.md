## 3. 事件总线 (Event Bus)

当系统变得复杂，需要将事件广播给多个订阅者时，**事件总线**比简单的观察者模式更有效。

### 3.1 核心组件

* **`EventBus` 结构体**：通常包含待投递/待处理事件的队列（常由 `Mutex` / 通道保护）以及订阅者标识（如递增 ID）。
* **`EventHandle`（句柄）**：订阅者通过句柄与总线交互，句柄持有订阅 ID 与对总线的引用（或 `Weak` 以避免循环引用）。

### 3.2 内存泄漏防御

如果订阅者任务被取消或句柄被丢弃，但没有显式退订，总线中的队列与映射可能持续堆积，导致**内存泄漏**。

* **解决方案**：为 `EventHandle` 实现 **`Drop`**，在句柄离开作用域时自动 `unsubscribe` / 清理队列中的该订阅者。
