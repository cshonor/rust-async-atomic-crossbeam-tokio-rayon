# 6.6 Building Our Event Bus Handle

## `EventHandle` 的职责

为每个订阅者提供安全交互入口，通常包含：

- **唯一 `subscriber_id`**
- 指向总线的 **`Arc<EventBus>`**（或弱引用以避免循环持有）

通过句柄：`subscribe` 时已注册队列；运行时 `next_event().await` 消费。

## 内存泄漏隐患

若句柄被**丢弃**却未 **unsubscribe**：

- `HashMap` 中该 ID 的 `VecDeque` 仍存在；
- 持续 `publish` 会使队列无限增长 → **OOM**。

## `Drop` 自动退订

为 `EventHandle` 实现标准 **`Drop`**：

```rust
impl Drop for EventHandle {
    fn drop(&mut self) {
        // 异步总线上注销 subscriber_id，并标记队列待回收
    }
}
```

离开作用域即清理，避免「忘记退订」类 bug。异步注销常需 `spawn` 或向总线发控制消息（见 §6.7 GC）。
