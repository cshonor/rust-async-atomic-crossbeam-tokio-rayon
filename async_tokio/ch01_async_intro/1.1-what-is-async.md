# 1.1 What Is Async?（什么是异步？）

> Demo：[1.1-what-is-async/1.1-what-is-async-join-demo.rs](./1.1-what-is-async/1.1-what-is-async-join-demo.rs)

## 核心梳理

- **高视角**：OS 调度器在少量 CPU 核心上**快速切换**线程/任务，营造「成千上万个程序在同时跑」的假象。
- **同步阻塞**：等 I/O 时线程**干等**（烧水站旁边等开）。
- **异步非阻塞**：等 I/O 时去干别的事，就绪后再继续（利用 **Dead Time**）。
- **`tokio::join!`**：在**不增加线程数**的前提下，并发等待多个异步操作；墙钟时间接近**最慢**那个，而非相加。

## 摩尔定律与 I/O 现实

单核算力增长放缓；服务端大量时间在**网络/磁盘**等待。异步的目标是 **I/O-bound** 场景下提高**吞吐与响应**，不是让 CPU 算得更快。

## 本仓库示例

`join!` + `tokio::time::sleep` 模拟并发等待；HTTP 并发见 §1.6。
