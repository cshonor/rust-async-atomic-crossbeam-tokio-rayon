# 11.8 Summary（总结）

## 全书收尾

异步系统要测的不只是「能跑」，还有 **死锁、竞态、背压、网络、poll 顺序**。

## 工程建议

- **测试与实现同步**（TDD 或至少同 PR）；
- 隔离模块用 **mockall + AAA**；
- 纯异步 trait 用 **每测独立 current_thread runtime**；
- 卡死用 **timeout**；竞态用 **多线程**；通道用 **满队列 + timeout**；HTTP 用 **mockito**；底层用 **tokio-test**。
