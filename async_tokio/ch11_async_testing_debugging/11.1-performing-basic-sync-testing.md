# 11.1 Performing Basic Sync Testing（基础同步测试）

## 测试对象

第九章 **带同步入口的隔离异步模块**：对外阻塞 API，对内 Tokio `spawn` + ID 映射。

## `mockall` + AAA

| 阶段 | 说明 |
|------|------|
| **Arrange** | 准备 mock 结构体 / trait |
| **Act** | 调用同步 Facade |
| **Assert** | 断言返回值与 mock 调用次数 |

- **`#[automock]`** 为 trait 生成 mock；
- **`expect_*` / `with` / `returning`** 约束行为；
- **无需启动完整系统** 的原子化单测。

## 驱动异步

测试中可用 **`#[tokio::test]`**、`block_on`，或仅测同步壳 + mock 依赖。
