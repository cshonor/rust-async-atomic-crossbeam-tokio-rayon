# 11.6 Testing Network Interactions（测试网络交互）

## 真实外服的问题

慢、不稳定；多线程测试可能在**服务端**制造竞态。

## `mockito`

在测试生命周期内于**本地**起 Mock HTTP 服务：

- 拦截请求、返回固定状态码与 Body（如 **201**）；
- **`expect(n)`** 断言调用次数；
- Base URL **可注入**，区分 mock / 预发 / 生产。

同类工具：**`wiremock`**（按 `Cargo.lock` 选型）。
