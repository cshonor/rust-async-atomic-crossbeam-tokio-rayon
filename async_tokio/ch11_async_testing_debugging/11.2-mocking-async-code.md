# 11.2 Mocking Async Code（模拟异步代码）

## 纯异步 Trait

对直接返回 **Future** 的 trait 做 Mock；稳定链路上常用 **`async-trait`** 将方法展开为 `async fn`，便于 `mockall` 生成实现。

## 测试隔离：单线程 Runtime

每个 **`#[tokio::test]`** 内单独构建：

```rust
let rt = tokio::runtime::Builder::new_current_thread()
    .enable_all()
    .build()
    .unwrap();
rt.block_on(async { /* 断言 */ });
```

避免多测试共享全局运行时导致**交叉污染**。

## AFIT 注意

若使用 **`impl Future`（AFIT）**，mock 生成器支持可能受限；书中多改为 **`async_trait`**，语义等价。
