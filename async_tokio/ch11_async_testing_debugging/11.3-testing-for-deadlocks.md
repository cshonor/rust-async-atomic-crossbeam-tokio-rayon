# 11.3 Testing For Deadlocks（测试死锁）

## 死锁与活锁

- **Deadlock**：任务互相等锁，整体停滞；
- **Livelock**：仍在运行但无进展（需业务层退避/重构）。

## `tokio::time::timeout`

```rust
use tokio::time::{timeout, Duration};

let result = timeout(Duration::from_millis(250), suspicious_work()).await;
assert!(result.is_err(), "应在超时内完成，否则疑似卡死");
```

超时 **不能替代** 根因分析，但可精准**判定**「挂起过久」。
