## 2. 唤醒器与执行器的从零实现

### 2.1 手动实现 Waker

* **`RawWaker` 与 `RawWakerVTable`**：用函数指针表描述 `clone` / `wake` / `wake_by_ref` / `drop` 行为，再 **`Waker::from_raw`** 构造 `Waker`。
* **职责**：`wake` 路径应把对应任务重新挂回就绪队列；教学版可先用**忙轮询 / yield** 代替完整就绪队列，但应清楚这与生产级 epoll/IOCP 驱动差距巨大。

### 2.2 构建执行器 (Executor)

* **任务队列**：常用 **`VecDeque`** 保存待轮询的 `Future`（多以 **`Pin<Box<dyn Future<...>>>`** 承载）。
* **轮询逻辑**：弹出任务 → 构造 **`Context`** → **`poll`**：
  * **`Ready`**：把结果写回通道/调用方并丢弃任务；
  * **`Pending`**：将任务放回队列尾部（或依赖 `Waker` 精确唤醒），进入下一轮。
