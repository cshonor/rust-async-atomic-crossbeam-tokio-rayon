### Rocket 简介

**Rocket**：高层 **Web 框架**，强调声明式路由与易用性（体验上常被比作 Python **Flask**）。

| 特点 | 说明 |
|------|------|
| 路由 | **`#[get("/path")]`、`#[post(...)]`** 等属性宏 |
| 编译器 | 书中时代常依赖 **nightly**；新版本请查官方文档 |
| 定位 | 快速做网站 / REST API，少写底层 HTTP 解析 |

### REST API + 数据库：`diesel` + `r2d2`

书中 **博客 CRUD** 典型栈：

| 组件 | 作用 |
|------|------|
| **`diesel`** | ORM：类型安全 SQL、迁移 |
| **`r2d2`** | **连接池** |
| **Rocket 路由** | `GET/POST/PUT/DELETE` → handler |

**Data Guards + Serde**：入参 JSON 自动反序列化（与 [Ch04](../stage04_serde_parse/) 一致）。

```rust
// 概念
#[post("/posts", data = "<post>")]
fn create(post: Json<NewPost>) -> Json<Post> { ... }
```

### 动态 HTML：Tera + Managed State

- **`Tera`**：模板引擎。  
- **`AtomicUsize`** 托管状态：线程安全访问计数（演示用）。

**选型**：生产还有 **axum**、**actix-web** 等；Rocket 重在理解「路由宏 + 提取器 + 状态」。
