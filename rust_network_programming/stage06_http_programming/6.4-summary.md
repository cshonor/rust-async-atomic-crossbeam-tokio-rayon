### 三库分工

| Crate | 角色 | 典型用途 |
|-------|------|----------|
| **Hyper** | HTTP 协议 + 异步 I/O 底座 | 自建服务器、网关 |
| **Rocket** | 全栈 Web 框架 | 博客 API、模板页 |
| **reqwest** | HTTP 客户端 | 调第三方 API、微服务 HTTP |

```text
写服务：Hyper（底层） 或 Rocket（高层）
写客户端：reqwest
数据格式：Serde JSON（Ch4）
运行时：Tokio（Ch3 阻塞 → Ch6/7 异步）
```
