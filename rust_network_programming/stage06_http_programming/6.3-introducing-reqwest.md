### reqwest 简介

**reqwest**：高层 **HTTP 客户端**，API 接近 Python **`requests`**。

| 能力 | 说明 |
|------|------|
| 方法 | `get`、`post`、自定义头、超时、代理 |
| 体 | JSON、表单、multipart |
| TLS | feature：`rustls-tls` / `native-tls` |

### 同步与异步

**同步**（CLI / 脚本）：

```rust
let client = reqwest::blocking::Client::new();
let resp = client.get("https://httpbin.org/get").send()?;
let body = resp.text()?;
```

**JSON + Serde**（与 Ch04 一致）：

```rust
let res: ApiResult = client.post(url).json(&payload).send()?.json()?;
```

**异步**（现代 Tokio）：

```rust
#[tokio::main]
async fn main() -> Result<(), reqwest::Error> {
    let body = reqwest::get(url).await?.text().await?;
    Ok(())
}
```
