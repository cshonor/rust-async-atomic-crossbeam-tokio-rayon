## 4.1 Serialization and deserialization using Serde（使用 Serde 序列化与反序列化）

> 书 §4.1 · 贯通稿：[notes/Ch04-…](./notes/Ch04-数据序列化反序列化与解析-学习笔记.md)

---

**Serde** = **Ser**ialize / **De**serialize；网络里常见 **JSON**（调试）与 **二进制**（体积/速度）。

```rust
#[derive(Serialize, Deserialize)]
struct Point3D { x: f64, y: f64, z: f64 }

let json = serde_json::to_vec(&p)?;
let back: Point3D = serde_json::from_slice(&json)?;
```

配合 [Ch3](../stage03_std_tcp_udp/) TCP 时注意**粘包**：长度前缀 / 换行 / Content-Length；Serde 只管「一段字节 ↔ 结构体」。
