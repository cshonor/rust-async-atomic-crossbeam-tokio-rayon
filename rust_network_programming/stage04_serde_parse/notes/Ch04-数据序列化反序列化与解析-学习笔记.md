## 4.1 Serialization and deserialization using Serde（使用 Serde）

**Serde** = Rust 序列化事实标准；支持 JSON、YAML、TOML、CSV 等。

```toml
[dependencies]
serde = { version = "1", features = ["derive"] }
serde_json = "1"
```

```rust
use serde::{Deserialize, Serialize};

#[derive(Serialize, Deserialize)]
struct Point3D { x: f64, y: f64, z: f64 }

let json = serde_json::to_vec(&p)?;
let back: Point3D = serde_json::from_slice(&json)?;
```

### 书中 TCP + JSON 示例

客户端读入 (x,y,z) → 序列化 → 服务器反序列化 → 算到原点距离 → 回写。

**粘包**：`TcpStream` 是流；需 **长度前缀** / 换行 / Content-Length。**Serde 不负责分帧**。

```rust
fn send_json(stream: &mut TcpStream, msg: &impl Serialize) -> std::io::Result<()> {
    let body = serde_json::to_vec(msg)?;
    let len = (body.len() as u32).to_be_bytes();
    stream.write_all(&len)?;
    stream.write_all(&body)?;
    Ok(())
}
```

## 4.1.1 Custom serialization and deserialization（自定义 Serde）

宏不够时手写 **`Serialize`** / **`Deserialize`**（**Visitor** 模式）。

### `Serialize`

`serialize_struct`、`serialize_field` 等指定字段名与布局。

### `Deserialize` + Visitor

`visit_map`、`visit_str`、`visit_f64`… 从输入逐步构造类型。

### `serde_test`

用 **Token stream** 断言序列化形状，无需完整 JSON round-trip。

也可用 `#[serde(rename)]` 等属性减少手写量。

## 4.2 Parsing textual data（解析文本数据）

HTTP 请求行等适合 **PEG + 解析器组合子**，不必整包 `Deserialize`。

### `nom`

| 工具 | 作用 |
|------|------|
| `tag!` | 匹配字面量 `b"GET "` |
| `take_until!` | 读到分隔符 |
| `do_parse!` / 组合子链 | 顺序组合 |

目标：`GET /path HTTP/1.1` → 方法、URL、版本。

调试：`dbg!`、`cargo expand`。

### `pom`（对比）

Trait + 运算符（`|`、`*`）写 PEG；与 nom 二选一深入即可。

完整 HTTP 见 [Ch06](../../stage06_http_programming/)。

## 4.3 Parsing binary data（解析二进制数据）

IP 头、自定义帧等用 **`nom` 二进制模式**。

### IPv6 首部（书中）

`bits!`、`take_bits!` 按位取：版本 4bit、流量类别 8bit、流标签 20bit… → 填入 `Ipv6Header`。

### 选型

| 方式 | 适用 |
|------|------|
| Serde + bincode/postcard | Rust 双方、有 schema |
| nom 按位/按字节 | 标准协议头、跨语言 |
| 固定头 + Serde 体 | 头 nom、负载 JSON |

与 Ch3 **`libpnet`**：抓包 vs 自定义解析器。
