## 3.2 A Simple UDP server and client（简单的 UDP 服务器与客户端）

> 书 §3.2 · 多播见 [3.2.1-udp-multicasting.md](./3.2.1-udp-multicasting.md)

---

UDP **无连接**，报文边界由协议保留。

| 角色 | API |
|------|-----|
| 绑定 | `UdpSocket::bind("127.0.0.1:PORT")?` |
| 收 | `recv_from(&mut buf)` → `(usize, SocketAddr)` |
| 发 | `send_to(&buf, addr)` |

| | TCP | UDP |
|---|-----|-----|
| 连接 | `connect` / `accept` | 无；每包带地址 |
| 语义 | 字节流 | **独立 datagram** |
