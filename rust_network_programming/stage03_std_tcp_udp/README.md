# Stage 03 — Rust 原生同步网络（std）

## 核心内容

- 阻塞式 TCP 服务端 / 客户端  
- UDP 单播、组播（若书中有）

## 学习定位

> **不懂同步 socket，很难真正理解 Tokio 里在抽象什么。**  
> 顺序建议：**阻塞 → 多路复用（概念）→ 异步运行时**。
