## 3.2.1 UDP multicasting（UDP 多播）

> 书 §3.2.1 · 贯通稿：[notes/Ch03-…](./notes/Ch03-使用Rust进行TCP和UDP编程-学习笔记.md)

---

- 多播地址常 **239.0.0.0/8**（如 `239.0.0.1`）。  
- **`join_multicast_v4(multicast, interface)`** 加入组播组。  
- 注意防火墙、网卡、TTL；局域网服务发现、日志汇聚等场景。

### 配套代码

| Bin | 说明 |
|-----|------|
| `demo_3_2_1_multicast_recv` | 绑定并 `join_multicast_v4`，打印收到的报文（需另终端或工具发向 `239.0.0.1:39191`） |

Windows 上可能需管理员权限或组播路由；失败时以笔记 API 为主、本 demo 为辅。
