### TCP 服务器：`TcpListener`

| 步骤 | API / 做法 |
|------|------------|
| 监听 | `TcpListener::bind("127.0.0.1:PORT")?` |
| 接受连接 | `listener.incoming()` → **`TcpStream`** |
| 并发 | 每连接 **`thread::spawn`** 处理，避免单线程阻塞全体客户端 |

**要点**：`bind` 后 **LISTEN**；`incoming()` 等价反复 `accept`；线程内 **`move`** 拿走 `TcpStream`。

### TCP 客户端：`TcpStream`

| 步骤 | API |
|------|-----|
| 连接 | `TcpStream::connect(addr)?` |
| 读写 | `Read` / `Write`；**`BufReader`/`BufWriter`** 减少 syscall |

### 读超时
