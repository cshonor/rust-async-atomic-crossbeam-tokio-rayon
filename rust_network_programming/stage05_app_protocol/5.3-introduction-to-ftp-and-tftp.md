## 5.3 Introduction to FTP and TFTP（FTP 与 TFTP 简介）

> 书 §5.3

---

| | FTP | TFTP |
|---|-----|------|
| 传输 | TCP，控制 21 + 数据通道 | **UDP**，无认证 |
| 生态 | `rust-ftp` | `tftp_server` |
| 场景 | 传统文件交换 | PXE / 嵌入式 |
