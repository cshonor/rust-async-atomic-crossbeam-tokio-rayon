## 5.1 Introduction to RPC（RPC 简介）

**RPC**：像调用本地函数一样调用远端过程。

| 角色 | 职责 |
|------|------|
| 客户端 | 序列化参数 → 请求 → 反序列化响应 |
| 服务端 | 收请求 → 执行业务 → 返回 |

### gRPC + Protocol Buffers

| 层 | 技术 |
|----|------|
| 传输 | **HTTP/2** on TCP |
| IDL | `.proto` |
| 编码 | **protobuf**（紧凑、有 schema） |
| 能力 | 一元 / 服务端流 / 客户端流 / 双向流 |

书中流程：写 `.proto`（如打车 `CabLocationRequest`、`FooBarService`）→ **`protoc-rust-grpc`** + `build.rs` 生成 Rust → 实现 server/client。

**现代对照**：**`tonic`** + **`prost`**（gRPC on Rust 主流）。

延伸：[Ch06](../../stage06_http_programming/) HTTP/2 · [Ch07](../../stage07_tokio_async_net/) 异步服务。

## 5.2 Introduction to SMTP（SMTP 简介）

- 互联网**发信**标准；通常 **TCP 25**。  
- 文本命令：`HELO`、`MAIL FROM`、`RCPT TO`、`DATA`…

### `lettre`

1. 定义邮件结构（如 `CrashReport`）  
2. 实现 **`SendableEmail`** / `Message` API  
3. **`SmtpTransport`**：主机、端口、**TLS**、凭据  
4. **`send`**

生产常用 **587 + STARTTLS** 或 **465**；凭据用环境变量。

## 5.3 Introduction to FTP and TFTP（FTP 与 TFTP 简介）

### FTP

| 项目 | 说明 |
|------|------|
| 端口 | 控制 **21** + 数据连接（主动/被动） |
| 库 | **`rust-ftp`** |
| 流程 | 连接 → 登录 → `put`（书中用 `Cursor` 内存缓冲上传） |

### TFTP

| 对比 FTP | TFTP |
|----------|------|
| 传输 | **UDP** |
| 认证 | **无** |
| 场景 | PXE、嵌入式引导 |
| 库 | **`tftp_server`** 本地提供文件下载 |

## 5.4 Summary（总结）

| 协议 | 传输 | 典型 crate |
|------|------|------------|
| gRPC | TCP + H2 | `protoc-rust-grpc` / `tonic` |
| SMTP | TCP | `lettre` |
| FTP | TCP 双连接 | `rust-ftp` |
| TFTP | UDP | `tftp_server` |
