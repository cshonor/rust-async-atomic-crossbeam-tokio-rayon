## 5.1 Introduction to RPC（RPC / 远程过程调用简介）

> 书 §5.1 · 贯通稿：[notes/Ch05-…](./notes/Ch05-应用层协议-学习笔记.md)

---

**RPC**：像调本地函数一样调远端方法；**gRPC** = HTTP/2 + **protobuf** + `.proto` 代码生成。

```text
.proto → protoc → server impl / client stub → TCP/HTTP2
```

现代 Rust 常 **`tonic` + `prost`**；本章 demo 用 **JSON over TCP** 演示 RPC 形状（无 protoc 工具链）。
