## 4. 新手易错点与核心认知

| 误区 | 正解 |
|------|------|
| Relaxed = 更新「更慢」 | 模型规定**顺序**不规定**时间**；快慢看缓存一致性，与 Ordering 无简单对应 |
| x86 不乱序就不用 Ordering | **编译器仍可重排**；错 Ordering 会生成错误机器码 |
| SeqCst 万能最安全 | 多数场景 RA 足够；SeqCst 掩盖分析、损性能 |
| Relaxed 当「数据就绪」标志 | 必须 Release + Acquire |

（与第 2 章衔接：`fetch_add` 回绕、CAS 用 `compare_exchange_weak` — 见 `../Chapter-02-Atomics/2.3-compare-and-exchange/2.3-compare-and-exchange-id-allocator-demo.rs`。）
