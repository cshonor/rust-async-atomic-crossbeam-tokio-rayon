## 2. 五大内存顺序（精读）

### ① `Ordering::Relaxed`（宽松）

| 项 | 内容 |
|----|------|
| **保证** | **无**跨线程 HB；仅同一原子变量的 **总修改顺序（Total Modification Order）** |
| **效果** | 可重排该操作与其他变量；他线程可能先看到原子更新，仍看不到此前对普通内存的写 |
| **场景** | 独立计数器、唯一 ID、与「别内存就绪」无关的统计 |
