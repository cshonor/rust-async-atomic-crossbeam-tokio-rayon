## 2. 写优先 `RwLock` — 状态机与代码骨架

书中使用 **`atomic_wait`**（封装 futex / `WaitOnAddress`）实现 `wait` / `wake_one` / `wake_all`。

### `state` 编码

- 读者数量 **× 2** 存入 `state`。  
- **偶数**：无写者排队 → 新读者可 `state += 2`。  
- **奇数**：有写者排队 → 新读者必须阻塞。  
- **`u32::MAX`**：写者持有写锁。

另设 **`writer_wake_counter`**：写者专用等待计数，由**最后一个读者**离开时在 `Drop` 里 `wake_one`。

### 核心逻辑（与书一致，节选）

```rust
// 依赖：atomic_wait = "..."  （书中示例；仓库未默认加入 Cargo.toml，仅作阅读参考）

use std::cell::UnsafeCell;
use std::sync::atomic::{AtomicU32, Ordering::{Acquire, Relaxed, Release}};
// use atomic_wait::{wait, wake_one, wake_all};

pub struct RwLock<T> {
    state: AtomicU32,
    writer_wake_counter: AtomicU32,
    value: UnsafeCell<T>,
}

impl<T> RwLock<T> {
    pub fn read(&self) -> ReadGuard<T> {
        let mut s = self.state.load(Relaxed);
        loop {
            if s % 2 == 0 {
                match self
                    .state
                    .compare_exchange_weak(s, s + 2, Acquire, Relaxed)
                {
                    Ok(_) => return ReadGuard { rwlock: self },
                    Err(e) => s = e,
                }
            }
            if s % 2 == 1 {
                // wait(&self.state, s);
                s = self.state.load(Relaxed);
            }
        }
    }

    pub fn write(&self) -> WriteGuard<T> {
        let mut s = self.state.load(Relaxed);
        loop {
            if s <= 1 {
                match self.state.compare_exchange(s, u32::MAX, Acquire, Relaxed) {
                    Ok(_) => return WriteGuard { rwlock: self },
                    Err(e) => {
                        s = e;
                        continue;
                    }
                }
            }
            if s % 2 == 0 {
                match self.state.compare_exchange(s, s + 1, Relaxed, Relaxed) {
                    Ok(_) => {}
                    Err(e) => {
                        s = e;
                        continue;
                    }
                }
            }
            let w = self.writer_wake_counter.load(Acquire);
            s = self.state.load(Relaxed);
            if s >= 2 {
                // wait(&self.writer_wake_counter, w);
                s = self.state.load(Relaxed);
            }
        }
    }
}

// ReadGuard / WriteGuard：Deref + Drop 中递减 state、必要时 wake 写者/读者（见全书完整版）
```

### 运行逻辑（写者饥饿如何被消除）

1. 写者发现仍有读者 → 将 **偶数 `state` 加 1 变奇数**（「写者等待中」）。  
2. 此后所有 **`read()`** 见奇数 → **不再加入**，进入 `wait`。  
3. 老读者陆续 `Drop`，`state` 减 2。  
4. **最后一个读者**唤醒写者 → 写者 CAS 为 `MAX` 独占。  
5. 写者 `Drop` 后 `wake_all` 读者（书中完整实现细节见原书）。

## 3. 与 `std::sync::RwLock` 的差异

| | 标准库 | 本章手写 |
|---|--------|----------|
| 目标 | 通用、安全 | 教学、写优先 |
| 写者饥饿 | 实现相关 | 显式拦截新读者 |
| 依赖 | OS 锁 | `AtomicU32` + `atomic_wait` |

日常开发 **优先用标准库**；读本章理解状态机即可。

## 4. 背诵卡

| # | 背这句 |
|---|--------|
| 1 | state 存读者数×2；偶=可进读者，奇=写者排队。 |
| 2 | 写者：偶数时 +1 拦新读者；wait 在 writer_wake_counter。 |
| 3 | 读者：仅偶数 CAS +2；奇数则 wait。 |
| 4 | MAX=写者持锁；最后读者 wake 写者。 |
