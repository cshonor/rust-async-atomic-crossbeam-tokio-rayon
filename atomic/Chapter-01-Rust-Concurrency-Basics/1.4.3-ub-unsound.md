## 1.4.3 UB 与 Unsound

---

### 1. UB 是什么

违反语言**内存模型 / 别名规则**时，编译器可假设「规则永不被打破」，从而：

- **指令重排**、删除「看似无效」的分支；
- 让 UB **之前**看起来正确的代码也产生荒谬结果（书中「**时光倒流**」式例子）。

### 2. Unsound（破防）

在 **`unsafe`** 里违背借用规则、人为制造数据竞争 → API 声称安全但实际可 UB → 称为 **Unsound**。  
（对比：[1.2.7 Leakpocalypse](./1.2.7-leakpocalypse-pitfalls.md) 是「安全 API 在 leak 下 Unsound」。）
