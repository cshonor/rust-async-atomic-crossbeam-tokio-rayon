## 1.1 Threads in Rust（Rust 中的线程）

现代 OS 通过快速切换**进程**实现并发；同进程内**线程**无内存隔离、**共享内存**交互。Rust 类型系统在编译期为共享提供严格保障。

### 进程与线程

| 概念 | 隔离 | 内存 | 交互 |
|------|------|------|------|
| **进程** | 相互隔离 | 默认不共享 | OS 快速切换，看起来「同时」 |
| **线程** | 同进程内无隔离 | **共享** | 通过共享内存交互 |

### 主线程与程序生命周期

- 每个程序从**主线程**执行 `main` 开始。  
- **`main` 返回 → 整个程序立即退出**，即使其他 `spawn` 出的线程仍在运行（未 `join` 的子线程会被终止）。  
- 要拿到返回值或确保子线程跑完，必须对 `JoinHandle` 调用 **`join()`**；子线程 **panic** 时 `join()` 返回带 panic 信息的 **`Result::Err`**。

### 线程标识（`ThreadId`）

- 标准库为每线程分配唯一 **`ThreadId`**。  
- 用途：复制、比较相等；**无其他特殊语义**，**不保证连续编号**。

### 创建线程与基础 API

| API | 要点 |
|-----|------|
| **`std::thread::spawn`** | 新线程跑闭包；闭包须 **`'static`** → 通常 **`move`** 转移所有权，**不能捕获非静态局部引用** |
| **`JoinHandle::join()`** | 阻塞等待线程结束；panic 时返回 `Err` |
| **`thread::Builder`** | `spawn` ≈ `Builder::new().spawn().unwrap()`；可设**栈大小**、**线程名**（调试）、返回 **`io::Result`**（资源不足时不直接 panic） |
| **`std::thread::scope`** | 子线程保证在作用域结束前结束 → 可**安全借用局部变量**（详见 [1.2](./1.2-scoped-threads.md)） |

**易错细节**：`println!` 底层对 **`Stdout::lock()`**，避免多线程输出在**字节级**被截断或交错（仍可能行级交错）。
