## 1.4.2 数据竞争（Data Race）定义

> 书 §1.4 · 索引：[1.4-borrowing-data-races](./1.4-borrowing-data-races.md) · 前：[1.4.1 危险](./1.4.1-shared-memory-danger.md) · 后：[1.4.3 UB](./1.4.3-ub-unsound.md)

---

> **一线程正在修改**某内存，**另一线程同时访问**（读或写）**同一块**内存，且至少一侧无同步 → **数据竞争**。

```rust
// 伪代码：两个线程无同步地写/读同一 i32 —— UB
// 线程 A: *ptr = 1;
// 线程 B: let x = *ptr;
```

在**安全 Rust** 里，普通 `&T` / `&mut T` 无法跨线程构成这种模式；问题常出现在 `unsafe`、错误使用 `static mut`、或与 C 互操作。
