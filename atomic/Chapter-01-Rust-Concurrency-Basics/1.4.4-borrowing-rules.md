## 1.4.4 借用规则如何防数据竞争

> 书 §1.4 · 索引：[1.4-borrowing-data-races](./1.4-borrowing-data-races.md) · 前：[1.4.3 UB](./1.4.3-ub-unsound.md) · 后：[1.4.5 路线图](./1.4.5-sync-roadmap-pitfalls.md)

---

Rust 对**单次线程内**的引用有两条铁律，推广到 [1.2 scope](./1.2-scoped-threads.md) 的多线程借用检查：

| 借用 | 准确称呼 | 规则 |
|------|----------|------|
| `&T` | **共享借用**（Shared Reference） | 可同时存在多个；**默认不可改** |
| `&mut T` | **排他借用**（Exclusive Reference） | 同一时刻**至多一个**活跃；写时无人共读 |

**一句话**：**共享读 OR 独占写**——编译期排除「一边写、一边读/写」。

```rust
use std::thread;

fn main() {
    let mut v = vec![1, 2, 3];
    thread::scope(|s| {
        s.spawn(|| println!("{:?}", v)); // 共享读 OK
        // s.spawn(|| v.push(4));        // 编译错误：不能同时 &mut
    });
}
```
